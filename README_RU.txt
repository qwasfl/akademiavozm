АКАДЕМИЯ ВОЗМОЖНОСТЕЙ — Android WebView

Приложение открывает https://lk.akademiavozm.ru внутри окна приложения.
Поддерживаются JavaScript, DOM Storage и cookies для входа в личный кабинет.
Кнопка «Назад» возвращает на предыдущую страницу сайта.

СБОРКА APK
1. Установите Android Studio (версия с поддержкой Android Gradle Plugin 8.7.3).
2. Откройте в Android Studio папку AkademiaVozmozhnostey.
3. Дождитесь синхронизации Gradle и установки Android SDK Platform 35.
4. Выберите Build -> Build Bundle(s) / APK(s) -> Build APK(s).
5. APK появится в app/build/outputs/apk/debug/app-debug.apk.

Для сборки нужен доступ к интернету для загрузки Gradle/Android Gradle Plugin и Android SDK.
Минимальная версия Android: 6.0 (API 23).
